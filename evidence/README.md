# Submission evidence to collect

The following files are **not** generated automatically because they must show your real environment:

- `2b_application_creation.txt`: run `pwd`, `python3`, import and call emotion_detector, exit, then run the tests.
- `3b_formatted_output_test.txt`: print the returned emotion dictionary.
- `4b_packaging_test.txt`: run the required package import command.
- `5b_unit_testing_result.txt`: run `python3 -m unittest -v test_emotion_detection.py`.
- `6b_deployment_test.png`: screenshot with valid input and a real emotion detection result.
- `7c_error_handling_interface.png`: screenshot of the blank input error.
- `8b_static_code_analysis.txt`: run `pylint server.py` and copy the actual score.

For Q1 and Q6, fork/push the repository under your own GitHub account and submit URLs to README.md and EmotionDetection/__init__.py.

For Q2, Q4, Q10, and Q13, the course requests snapshots from earlier stages. The final files here reflect the completed project. Use version control or the relevant earlier-stage code in your submission if the grader expects those exact snapshots.
